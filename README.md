## How to Use

1. Go to https://strudel.cc
2. Copy the contents of any `.strudel` file
3. Paste into the Strudel REPL
4. Press **Ctrl+Enter** (or **Cmd+Enter** on Mac) to play
5. Press **Ctrl+.** (dot) to stop
6. Modify parameters in real-time for live coding

## Customization Ideas

### Make it MORE chaotic:
- Increase `degradeBy()` values (0.9 = 90% removal)
- Add more `rand` and `choose()` functions
- Increase `crush` and `coarse` amounts
- Use more `sometimes()` and `often()` randomization

### Make it HARSHER:
- Increase `shape()` and `distort()` values
- Lower `crush()` values (2-3 for maximum bit destruction)
- Increase `coarse()` for more sample rate reduction
- Push `lpq()` and `bpq()` resonance higher

### Change the tempo:
```javascript
setcps(YOUR_BPM/60/4)  // e.g., setcps(200/60/4) for 200 BPM
```

### Add more glitching:
```javascript
.stut(8, 0.5, 1/128)    // 8 stutters with 50% decay
.scramble()              // randomize event order
.degradeBy(0.8)         // remove 80% of events
```

## Technical Notes

All compositions use:
- **Aggressive bit crushing** (crush 2-7, lower = harsher)
- **Sample rate destruction** (coarse 8-64)

- **Random degradation** (degradeBy 0.2-0.9)

- **Perlin/rand signals** for organic chaos
