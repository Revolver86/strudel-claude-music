## How to Use

4. Press **Ctrl+Enter** (or **Cmd+Enter** on Mac) to play
5. Press **Ctrl+.** (dot) to stop
6. Modify parameters in real-time for live coding

## Customization Ideas

### Make it MORE chaotic:
- Increase `degradeBy()` values (0.9 = 90% removal)
- Add more `rand` and `choose()` functions
- Increase `crush` and `coarse` amounts
- Use more `sometimes()` and `often()` randomization

### Make it HARSHER:
- Increase `shape()` and `distort()` values
- Lower `crush()` values (2-3 for maximum bit destruction)
- Increase `coarse()` for more sample rate reduction
- Push `lpq()` and `bpq()` resonance higher

### Change the tempo:
```javascript
setcps(YOUR_BPM/60/4)  // e.g., setcps(200/60/4) for 200 BPM
```

### Add more glitching:
```javascript
.stut(8, 0.5, 1/128)    // 8 stutters with 50% decay
.scramble()              // randomize event order
.degradeBy(0.8)         // remove 80% of events
```

## Common Pitfalls & Solutions

### ⚠️ Sound Not Found Errors

**Problem:** `error: sound click not found! Is it loaded?`

**Cause:** Not all sound names exist in Strudel's library. Common non-existent sounds include:
- `click` ❌ (doesn't exist)
- `clk` ❌ (doesn't exist)
- `metronome` ❌ (doesn't exist)
- `tick` ❌ (doesn't exist)

**Solution:** Use actual available percussion sounds:

```javascript
// For metronome/click sounds, use:
sound("rim")         // ✓ Rimshot (bright, percussive)
sound("cp")          // ✓ Clap (sharp attack)
sound("hh")          // ✓ Hi-hat (short, crisp)

// Add high-pass filter for brighter metronome:
sound("rim*4").hpf(2000)  // Clean, clock-like pulse
```

### Available Drum Samples

**Verified working sounds:**
- `bd` - Bass drum/kick
- `sd` - Snare drum
- `hh` - Hi-hat (closed)
- `oh` - Open hi-hat
- `cp` - Clap
- `rim` - Rimshot
- `lt` / `mt` / `ht` - Low/mid/high toms
- `rd` - Ride cymbal
- `cr` - Crash cymbal

**Synthesizer waveforms:**
- `sine` - Pure sine wave
- `sawtooth` - Bright, buzzy
- `square` - Hollow, digital
- `triangle` - Soft, mellow

**Noise generators:**
- `white` - White noise
- `pink` - Pink noise (softer)
- `brown` - Brown noise (warmest)

### Other Common Issues

**Multiple sample variations:**
```javascript
sound("bd:0")   // First bass drum sample
sound("bd:1")   // Second variation
sound("bd").n(2)  // Third variation (alternative syntax)
```

**Case sensitivity:**
```javascript
sound("BD")      // ❌ Wrong - will not work
sound("bd")      // ✓ Correct - lowercase
```
