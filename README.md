## How to Use

1. Go to https://strudel.cc
2. Copy the contents of any `.strudel` file
3. Paste into the Strudel REPL
4. Press **Ctrl+Enter** (or **Cmd+Enter** on Mac) to play
5. Press **Ctrl+.** (dot) to stop
6. Modify parameters in real-time for live coding

## Customization Ideas

### Make it MORE chaotic:
- Increase `degradeBy()` values (0.9 = 90% removal)
- Add more `rand` and `choose()` functions
- Increase `crush` and `coarse` amounts
- Use more `sometimes()` and `often()` randomization

### Make it HARSHER:
- Increase `shape()` and `distort()` values
- Lower `crush()` values (2-3 for maximum bit destruction)
- Increase `coarse()` for more sample rate reduction
- Push `lpq()` and `bpq()` resonance higher

### Change the tempo:
```javascript
setcps(YOUR_BPM/60/4)  // e.g., setcps(200/60/4) for 200 BPM
```

### Add more glitching:
```javascript
.stut(8, 0.5, 1/128)    // 8 stutters with 50% decay
.scramble()              // randomize event order
.degradeBy(0.8)         // remove 80% of events
```

## Technical Notes

All compositions use:
- **Aggressive bit crushing** (crush 2-7, lower = harsher)
- **Sample rate destruction** (coarse 8-64)
- **Heavy waveshaping** (shape 5-30)
- **Random degradation** (degradeBy 0.2-0.9)
- **Euclidean rhythms** for polyrhythmic complexity
- **Perlin/rand signals** for organic chaos
- **Multiple layered patterns** via stack()

## Philosophy

**Compositions 01-07** reject clean production, stable rhythms, consonant harmony, predictable structures, and digital perfection. They embrace digital decay, structural chaos, dissonant brutality, lo-fi aesthetics, and outsider experimentalism.

**Composition 08 (Eigengrau)** explores the opposite extreme - rejecting loudness, aggression, density, and chaos. It embraces quietness at the threshold of perception, psychoacoustic phenomena, granular texture, extreme patience, and the sonic representation of consciousness itself.

Together, these pieces explore the full spectrum from **maximum sonic assault** to **minimum perceptible sound** - from the loudest possible digital chaos to the quietest perceivable baseline of consciousness.
